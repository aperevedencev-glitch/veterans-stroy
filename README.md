# Ассоциация ветеранов строительной отрасли — сайт (прототип)

Одностраничный интерактивный прототип сайта ассоциации:

- ИИ-консультант по стройматериалам, дизайну, ремонту и архитектуре (ответы имитируются);
- каталог специалистов-ветеранов, запись на видео- и чат-консультации;
- членство и оплата взноса (оплата имитируется);
- **Площадка СРО** — каталог компаний-членов СРО, биржа заказов, тендеры (44-ФЗ / 223-ФЗ), специалисты НРС;
- кабинеты члена, специалиста и менеджера, журнал событий для Битрикс24.

Все данные на сайте — примеры. Переключение ролей — полоса «Смотреть как» вверху страницы.

## Запуск

Сайт — один файл `index.html` без сборки. Откройте его в браузере или включите GitHub Pages (Settings → Pages → Branch: `main`, папка `/`).
