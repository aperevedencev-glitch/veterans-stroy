# Промпт для создания формы-опросника

Промпт воспроизводит форму из этой папки (`index.html`) и подходит для любого похожего текста с вопросами. Замените блок «ИСХОДНЫЙ ТЕКСТ» своим текстом. Логотип FlowLink уже вставлен; при необходимости замените его SVG-код.

```
Сделай одностраничную HTML-форму (анкету) для ответов на вопросы из текста ниже.

ИСХОДНЫЙ ТЕКСТ:
[вставьте сюда текст с вопросами]

СОДЕРЖАНИЕ
1. Найди в тексте все вопросы и сгруппируй их по смысловым блокам так, как они разделены в тексте (например: «44-ФЗ и 615-ПП», «223-ФЗ», «Технические вопросы»). Нумерацию вопросов сохрани.
2. Если в тексте есть главный или итоговый вопрос («начните с ответа на вопрос…»), вынеси его первым, отдельной выделенной карточкой со звёздочкой вместо номера.
3. Для каждого вопроса:
   – короткое пояснение «зачем спрашиваем» в 1–2 предложения, своими словами по тексту;
   – 2–4 варианта ответа: переключатели, если ответ один, флажки, если можно выбрать несколько;
   – если в вопросе есть уточнение («есть ли справочник…», «с какой даты»), добавь второй ряд вариантов или короткое текстовое поле;
   – поле «Комментарий».
4. Над вопросами поля: «Организация», «Отвечает (ФИО, должность)», «Дата» (по умолчанию сегодня).

ФУНКЦИИ
– Липкая полоса прогресса сверху: «заполнено N из M», отвеченные вопросы меняют цвет номера.
– Кнопка «Собрать ответы»: собирает всё в читаемый текст (шапка, блоки, вопрос → ответ → комментарий, пропуски обозначены «—») и выводит в поле только для чтения.
– Кнопка «Скопировать»: копирует текст в буфер; если браузер не дал доступ, выделяет текст и пишет «нажмите Ctrl+C».
– Кнопка «Очистить форму» с подтверждением повторным нажатием (без alert/confirm).
– Черновик сохраняется в localStorage при каждом вводе и восстанавливается при открытии; все обращения к localStorage в try/catch.
– Форма никуда не отправляет данные.

ОФОРМЛЕНИЕ
– Один самодостаточный файл index.html: стили и скрипт внутри, без фреймворков. Шрифты с Google Fonts с кириллицей: PT Serif для заголовков, Golos Text для текста, JetBrains Mono для номеров и меток.
– Строгий деловой стиль: светлый холодный фон, белые карточки с тонкой рамкой, акцент тёмно-синий, главный вопрос выделен янтарным.
– Светлая и тёмная тема через CSS-переменные и prefers-color-scheme.
– Корректно на телефоне (от 360 px): без горизонтальной прокрутки, отступы по бокам от 16 px.
– Доступность: у каждого поля id и подпись, видимый фокус, учёт prefers-reduced-motion.

– Справа нарисованный в SVG дружелюбный робот в той же гамме (градиент индиго → бирюзовый) с планшетом, на котором отмечены пункты. Робот моргает, огонёк на антенне мигает. На узком экране робот уходит над заголовком.
– Надзаголовок мелким моноширинным шрифтом, заголовок, вводный абзац с инструкцией, как заполнять.

РЕЗУЛЬТАТ
Выдай готовый файл index.html, который можно сразу выложить на GitHub Pages.
```
