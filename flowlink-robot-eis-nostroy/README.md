# FlowLink · Робот ЕИС → НОСТРОЙ

Веб-приложение для Ассоциации СРО «Стройкорпорация» (СРО-С-130-21122009): договоры членов СРО из ЕИС → сверка с членом СРО и заказчиком → один пакет для Единого реестра НОСТРОЙ.

## Станции

1. **Выгрузка из ЕИС.** Члены СРО и их контракты 44-ФЗ / договоры 223-ФЗ: действующие и исполненные с 01.01.2017. Рядом — уровень ОДО и обязательства по реестру НОСТРОЙ; расхождения подсвечены («в НОСТРОЙ обязательства 0», «нет права ОДО», «срок истёк, в ЕИС не закрыт»).
2. **Сверка с контрагентом.** Письмо члену СРО со списком его договоров («да / нет / исправить»). Ответ отмечается кнопками «Подтвердить», «Расхождение» (с верной ценой и датой) или «Не наш». При расхождении — письмо заказчику.
3. **Пакет для НОСТРОЙ.** Все подтверждённые договоры всех членов в одном файле `.xlsx` (листы «Договоры» и «Сводка по членам») или `.csv`. После загрузки в кабинет СРО пакет отмечается как переданный.

Все действия пишутся в журнал.

## Запуск

Страница — один файл `index.html` и данные `data/members.json`, сборка не нужна.

- **GitHub Pages:** откройте `…/flowlink-robot-eis-nostroy/` на сайте репозитория.
- **Локально:** `python -m http.server` в этой папке и откройте `http://localhost:8000`. Двойной клик по файлу не подойдёт: браузер не даст прочитать `data/members.json`.

В автономном режиме ход сверки хранится в браузере (localStorage), письма открываются в почтовой программе. В версии внутри Claude сверка общая для всех, кому открыт доступ, а письма создаются черновиками в Gmail.

## Данные

`data/members.json` — 123 члена СРО из Единого реестра НОСТРОЙ (выгрузка 19.10.2026) и договоры из ЕИС по всем 123 членам (выгрузка 19–20.10.2026). `eis_full.json` — полная выгрузка ЕИС и ClearSpending из Supabase, обновляется workflow «SRO EIS sync» (Actions → Run workflow).

Формат записи: `inn, name, ogrn, lvl, odo, liab, eis ("checked" | "queue"), contracts[]`, где договор — `reg, law, st ("active" | "done"), cust, price, date, until, obj`.

Регулярную выгрузку из ЕИС по токену делает модуль [`eis2nostroy`](../eis2nostroy) — его файлы `nostroy_*.csv` подходят для обновления `data/members.json`.

## Загрузка в НОСТРОЙ

Публичного описания загрузки одним файлом в Единый реестр нет: в кабинете СРО договоры подтягиваются из ЕИС или вносятся вручную. Если в кабинете есть шаблон импорта, формат пакета подстраивается под него в функции `packRows()`.
