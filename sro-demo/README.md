# Демо-стенд FlowLink для СРО «Стройкорпорация»

Одна страница для презентации исполнительному директору: слайды, рабочий робот «ЕИС → сверка → НОСТРОЙ» и терминал члена СРО. Все кнопки работают.

Открыть: https://aperevedencev-glitch.github.io/veterans-stroy/sro-demo/

Инструкция простыми словами: https://aperevedencev-glitch.github.io/veterans-stroy/sro-demo/guide.html (ссылки в ней открывают нужный блок стенда).

- Данные настоящие: 123 члена СРО и 2 725 договоров из ЕИС (открытые сведения), встроены в страницу.
- Ничего не отправляется и не сохраняется: письма показываются текстом, ответы живут только в открытом окне. Кнопка «Сбросить демо» возвращает всё к началу.
- Вход в терминал в демо: любой ИНН из списка и код `DEMO-SEQA`; вход для СРО — любой ключ.
- Ссылки на блоки: `#robot-1`, `#robot-2`, `#robot-3` (станции), `#terminal-member`, `#terminal-demo`, `#terminal-op` (входы терминала), `#s1`…`#s12` (слайды).
